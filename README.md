# hftest
Test project for HUB
This is an example of controlling HUB's LEDs using this pseudocode:

1. 3 <red>reds</red> 🔴
2. 3 <blue>blues</blue> 🔵
3. 3 <green>greens</green> 🟢
4. 3 <yellow>yellows</yellow> 🟡

The cycle will repeat after.

Developed Task
